## 已知限制与后续

- 保存采用未压缩 JSON + base64，含原文件和派生缓冲，较大素材有显著文件/内存成本；打开上限 512 MB。后续再分块/压缩。
- 采样、网格烘焙与工程编码仍主要在主线程。任务版本校验已建立，Worker、取消及性能分析在阶段二继续。
- 元数据与 TypedArray 采用内部不变约定，命令通过替换数据提交；尚未引入代理式强制只读缓冲。
- 当前颜色/名称/位置修改保留点 ID；重新采样建立新 ID，尚未实现稳定匹配或锁点重采样。
- 原 GLB 烘焙仍主要保留三角形；子网格/UV/特征来源扩展按后续阶段实施。
- 背景最长边降采样到 8192，线稿为 1024；原始文件始终随工程保存。
- UI 保留原布局并加项目/编队管理。完整工作站面板和常驻时间轴按阶段三/四实现。
- 自动保存属于当前浏览器本机站点数据，不代替显式下载的工程文件。
