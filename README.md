# 点阵飞行 / DroneShow Studio

基于本地 Three.js 的无人机点阵演示与编队编辑器。当前完成架构迁移第一阶段：多编队、公共项目数据、独立编辑、工程保存/打开、自动保存、撤销/重做。开发路线见 [架构评估](docs/ARCHITECTURE_REVIEW.md)。

## 启动

**在线版（推荐，打开即用，无需安装任何东西）**

<https://andywang777.github.io/drone-show/>

由 GitHub Pages 托管，纯静态、无后端。打开网页即可使用，所有数据都在你自己的浏览器里处理（模型、线稿、工程文件不会上传到服务器）。首次打开后也可以继续离线使用。

**本机版（需要自己起一个静态服务）**

本页依赖 ES 模块与模块化 Web Worker，浏览器禁止在 `file://` 下加载它们——**直接双击 `index.html` 会出现「按钮没反应」**。请任选一种方式：

```bash
npm start          # 然后访问 http://127.0.0.1:4180
```

macOS 也可以直接双击 `启动点阵飞行.command`，它会启动服务并自动打开浏览器。无需 `npm install`，依赖已放在 `vendor/`。

> 用 `file://` 打开时页面顶部会自动给出提示与在线版入口，不会静默失败。

## 部署到 GitHub Pages

仓库根目录即为站点根目录，无需构建步骤：

- `index.html` 是入口页，所有资源都使用相对路径，可直接部署在 `用户名.github.io/仓库名/` 这类子路径下。
- `.nojekyll` 已加入，跳过 Jekyll 处理，避免下划线开头的文件被忽略。
- 在仓库 Settings → Pages 中选择 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，保存后等待一两分钟即可。

> `.mjs` 模块文件由 GitHub Pages 以正确的 JavaScript MIME 类型提供；换成其他静态托管（Nginx/Apache 等）时需确认已为 `.mjs` 配置 `text/javascript`。

## 编队与素材

- 上传 GLB 或 PNG/JPG/WebP 线稿，每次成功导入都会添加一个独立编队；在“编队列表”切换。
- 当前编队可改名、复制、删除、调整数量、RGB、时长和 XYZ 位置；其他编队不变。示例球形/螺旋/立方体通过“添加”按钮新建。
- 1–10,000 点，时长 3–60 秒。位置以米表示，Y 为高度；编队局部坐标与世界位置分离。此阶段未增加尺寸缩放与最小间距约束。
- GLB：100 MB/200 万三角形上限；资源必须内嵌；支持 Draco/Meshopt，KTX2 暂不支持。解析默认姿态并烘焙世界变换，统一归一化到 22 m 尺度，再生成表面点阵；可显示对齐的参考网格。
- 线稿：20 MB/4000 万输入像素以内，处理最长边 1024 像素；支持深浅线条及透明背景。沿识别区域布点，不细化成中心线，不生成三维体积。选中线稿编队后调整阈值重新采样。新导入识别失败会保留待处理草稿，可调整参数后“重新识别”或放弃，当前工程不变。
- 重新采样会产生新逻辑点 ID；颜色、名字和位置编辑保留点 ID。当前没有实际飞行 droneId 指派。

## 工程保存与撤销

- “保存工程”生成 `.droneshow.json`，包含全部编队、精确点集、生成参数、颜色/时长/位置、原始素材和背景。打开后可继续重新采样，无需重新上传源文件。
- 使用版本化 JSON + base64 TypedArray 缓冲，优先保证可恢复性；此阶段尚未压缩，文件可能较大。打开上限 512 MB；源图/网格与派生数据会增加内存占用。
- 编辑后约 600 ms 自动保存到此浏览器的 IndexedDB。刷新后点击“恢复自动保存”；不会在启动时自动覆盖新工程。浏览器清理站点数据会删除本机自动保存，重要项目请手动下载。
- 撤销/重做保留最多 30 个编辑步骤；新建/打开、导入、删除、数量、颜色、位置及背景修改均可撤销。输入框之外可用 Cmd/Ctrl+Z、Cmd/Ctrl+Shift+Z。
- 自动保存不是手动工程文件；“请求下载”也不意味着已验证磁盘保存位置，下载位置由浏览器决定。

## 背景、预览与媒体导出

- 支持本地 PNG/JPG/WebP 背景，居中等比裁切。背景最长边最多 8192 像素并受本机纹理限制；设置背景隐藏网格，移除恢复。
- PNG/JPG 保存当前视角，包括点阵、背景及开启的参考模型，不包含编辑面板。
- 录制从地面起飞到当前编队自动停止，可提前保存；目标 30 fps，无音轨；优先 WebM，支持时回退 MP4。录制期间锁定工程编辑，仍可转动视角；切后台取消录制。
- 动画仍为旧版演示插值，未实现编队间安全转场、2.5D、统一关键帧或实际飞控轨迹导出。这些按后续阶段实施。

## 模块与测试

- `project/`：数据契约、校验、事务历史、工程序列化与自动保存。
- `assets/`：素材适配器及公共局部点集生成入口。
- `viewport/`：Three.js 对象、相机、点缓冲、参考网格、背景。
- `app.js`：UI 到项目命令的协调与现有演示播放。
- `media.js`：独立图片/视频导出，编辑锁通过应用回调协调。
- `formation.mjs` / `lineart.mjs`：保留的采样算法。

`npm test` 运行算法和工程契约测试。`node tests/create-sample.mjs` 可重建 GLB 样例。第一阶段验证记录见 `docs/STAGE1_VERIFICATION.md`。
