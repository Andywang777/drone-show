# 点阵飞行

Three.js 实现的 可配置数量的无人机光点编队可视化，支持本地 GLB 上传、三维旋转缩放、播放暂停、进度拖动、重新编队和参考模型。

## 开启

在本目录运行 `npm start`，浏览器打开 http://127.0.0.1:4178 。无需 npm install，Three.js 0.185.0 和加载器已保存在 vendor 中。依赖遵守 vendor/LICENSE。

macOS 也可以直接双击 `启动点阵飞行.command`：它会启动服务并自动打开浏览器（关闭弹出的终端窗口即停止服务）。

> ⚠️ 不要直接双击 `index.html`。用 file:// 打开时浏览器会拦截 ES 模块脚本，页面框架能显示，但所有按钮点了都没有反应（上传、播放均无效）。必须通过上面的本地服务访问；页面检测到这种情况时会在顶部给出提示。

默认显示球形编队。点击“播放”从地面阵列起飞；上传 GLB 后按当前无人机数量生成点阵并开始飞行。可用 samples/torus-knot.glb 测试。重新编队返回起点，按播放开始。飞行时长支持 3–60 秒。拖动场景旋转，滚轮缩放，右上按钮复位视角。手机支持触摸。

## 模型支持

- 单文件、资源内嵌的 GLB，最大 100 MB、200 万三角形；支持 Draco 和 Meshopt。
- 以默认姿态处理网格、世界变换、蒙皮、形变和实例；按世界坐标三角形面积采样，统一缩放和抬高。
- 只采样表面，不填充体积；按比例采样不保证每个微小细节都有光点。
- 数量支持 1–10,000 架（默认 1,000）；修改后自动重新采样已上传模型，同时更新示例编队、起飞阵列和数量显示，无需重新上传。
- 拾色器和 RGB 数值（0–255）可实时设置全部光点颜色，不提取原模型纹理；KTX2 纹理暂不支持。
- 模型在本机内存处理，不发送到服务器，不保存上传文件，刷新后需要重新选择。
- 动画为概念展示，没有最小间距约束、避碰、动力学或实际飞控输出。

## 验证

`npm test` 验证采样与动画核心。`node tests/create-sample.mjs` 重新生成合法/无效 GLB 测试文件。浏览器检查与视觉对照记录见 docs/verification.md。

## 背景与导出

- 在“背景与导出”上传 PNG、JPG 或 WebP（最大 20 MB），背景等比铺满并居中裁切，自动隐藏地面网格。移除后恢复默认场景。背景仅在本机处理。
- 选择 PNG 或 JPG，点击“导出图片”下载当前三维画面，包含背景、光点及已开启的参考模型，不含操作面板。分辨率取当前场景画布像素尺寸。
- 点击“录制视频”从起飞开始，按飞行时长实时录制，成形后自动下载；也可点击“停止并保存”提前结束。录制为 30 fps 目标帧率的无声视频，浏览器支持时使用 WebM，否则尝试 MP4。录制期间仍可旋转视角，编队设置暂时锁定。
- 视频固定为开始录制时的画布尺寸。保持页面在前台，切到后台会取消录制并提示重新开始；实际帧率受设备性能影响。文件通过浏览器下载，保存位置由浏览器设置决定。

## 二维线稿点阵

点击“上传二维线稿”，选择 PNG、JPG 或 WebP（20 MB 以内）。默认识别浅底深色线条；黑底白线可切换“线条颜色”。支持透明底，透明区域不参与采样。识别不到线条时可调整阈值，无需重新上传。

线稿按最长边 1024 像素处理，沿识别出的线条区域采样，保持图形比例并生成竖直 XY 平面点阵（不推断三维体积，也不将粗线自动细化为中心线）。上传后使用正面视角；数量、RGB、播放、背景和图片/视频导出均可继续使用。在“编队类型”中可切换已上传的 GLB 和线稿。照片、阴影和实心区域也会被当作笔画，建议使用干净的高对比度线稿。
